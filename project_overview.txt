1. PROJECT SUMMARY
------------------
CinePredict AI is a state-of-the-art, full-stack Machine Learning web application 
built using Python, Streamlit, Google Gemini API, Scikit-Learn, Pandas, and Plotly. 
The platform forecasts box office collections (in ₹ Crores) for movies across major 
Indian and Global film industries—including Bollywood, Dhollywood (Gujarati), 
South Indian, Hollywood, and Pan-India releases.

In addition to revenue forecasting, CinePredict AI leverages Google's Generative AI 
(Gemini 1.5 Flash) to evaluate movie storyline summaries on the fly and compute a 
commercial Hype Score (1.0 to 10.0). Every user-submitted movie entry is dynamically 
persisted into `movie_data.csv` to scale the ML training database in real time.

3. DATASET SCHEMA (`movie_data.csv`)
------------------------------------
The dataset maintains 10 structured attributes for historical and live entries:

1. `Movie Name`: Title of the film (String)
2. `Industry`: Film Industry (Bollywood, South Indian, Hollywood, Dhollywood, Pan-India)
3. `Genre`: Film Genre (Action, Comedy, Drama, Sci-Fi, Thriller, Horror, Romance, Fantasy, Animation)
4. `Lead Actors`: Main star cast; uses '+' notation for multi-starer films (e.g. Shah Rukh Khan + Hrithik Roshan)
5. `Co-Actors`: Supporting actors and director details
6. `Budget`: Production budget in ₹ Crores (Float)
7. `Description`: Plot narrative and storyline summary
8. `Festival Release`: Holiday or festival release window flag (Yes / No)
9. `Hype Score`: Generative AI / Algorithmic rating on a 1.0 to 10.0 scale (Float)
10. `Predicted Box Office Collection`: Total gross box office collection in ₹ Crores (Float)


4. HIT / FLOP CLASSIFICATION METRIC LOGIC
------------------------------------------
Commercial performance status is automatically assigned based on the Return on Investment (ROI) ratio:

  ROI Ratio = Predicted Box Office Collection / Production Budget

  • 🔥 All-Time Blockbuster / Super Hit : ROI >= 2.5x Budget
  • ✅ Hit Movie (Safe & Profitable)    : 1.3x <= ROI < 2.5x Budget
  • ⚠️ Average / Moderate Return        : 1.0x <= ROI < 1.3x Budget
  • ❌ Flop / Loss Risk                 : ROI < 1.0x Budget


5. ANALYTICS & INSIGHTS DASHBOARD CHARTS
---------------------------------------
The Analytics tab provides a dropdown selector with 5 dynamic, dark-themed Plotly charts:

1. Industry-wise Average Collection: Grouped bar chart comparing average collection vs budget across industries.
2. Top 10 Highest Grossing Movies: Horizontal bar chart showing top box office performers in the dataset.
3. Budget vs Collection Analysis: Interactive scatter plot with linear trendlines (bubble size scaled by Hype Score).
4. Hype Score Impact on Collection: Scatter plot analyzing how AI Hype Score and festival releases correlate with box office gross.
5. Genre-wise Movie Distribution: Interactive donut chart displaying genre market share in the database.


6. STEP-BY-STEP INSTALLATION & RUNNING LOCALLY
----------------------------------------------
Prerequisites: Python 3.9+ installed on your system.

Step 1: Clone or navigate to project directory:
   cd CinePredict-AI

Step 2: Install dependencies:
   pip install -r requirements.txt

Step 3: Run Streamlit application:
   streamlit run app.py

Step 4: Open your web browser at `http://localhost:8501`. Enter your optional Google Gemini API Key in the sidebar or run using the automatic fallback engine.


7. DEPLOYMENT TO HUGGING FACE SPACES
------------------------------------
1. Sign up/log in at https://huggingface.co/ and click "New Space".
2. Select "Streamlit" as the Space SDK and set visibility to Public.
3. Upload all project files (`app.py`, `movie_data.csv`, `requirements.txt`, `project_overview.txt`, `README.md`).
4. Go to Space Settings -> Repository Secrets -> Add New Secret:
   - Secret Name: `GEMINI_API_KEY`
   - Secret Value: <Your_Actual_Google_Gemini_API_Key>
5. Hugging Face will automatically build and host the live web application!
